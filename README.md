# Portfólio — Isabella Nicoliche

Página de portfólio pessoal, desenvolvida em HTML e CSS puro, como parte de um trabalho acadêmico com requisitos mínimos de estrutura semântica e conteúdo.

🔗 (https://isabellanicoliche.github.io/Porfolio-Isabella/)

## 📌 Sobre o projeto

O site é uma landing page única (single page) dividida em três seções principais, com o objetivo de apresentar quem sou, meus projetos e formas de contato.

## 🧩 Estrutura

- **Header** — navegação fixa (sticky) com links para as seções
- **Sobre** — apresentação pessoal e foto
- **Projetos** — cards com alguns projetos desenvolvidos, cada um linkando para o repositório no GitHub
- **Contato** — links para LinkedIn e GitHub
- **Footer** — crédito de desenvolvimento

## 🛠️ Tecnologias

- HTML5 (estrutura semântica: `header`, `main`, `section`, `footer`)
- CSS3 (Flexbox, Grid, variáveis CSS, media queries para responsividade)
- Google Fonts (Lora + Work Sans)
